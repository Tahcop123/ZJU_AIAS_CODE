# ZJU_AIAS_CODE

浙江大学研究生课程 **《人工智能算法与系统》** 课程作业代码与报告。

本仓库主要用于记录课程作业中使用的代码、训练脚本以及相关报告，同时给后续选课的同学提供一些参考。

> **说明：** 本仓库内容仅供学习与交流使用。课程平台、数据集、API 以及具体任务要求可能会随学期发生变化，请以当学期课程要求和 MO 平台说明为准。

---

## 项目简介

课程作业主要在学校提供的 **MO 平台** 上完成。

其实整体流程并不复杂，核心就是：

1. 根据作业要求修改或补全代码；
2. 将代码上传至 MO 平台；
3. 使用平台提供的算力进行模型训练；
4. 保存并记录训练得到的模型权重；
5. 在 `main.py` 中填写对应的权重路径；
6. 提交程序并在平台上测试；
7. 根据测试结果进一步调整模型或参数。

刚开始做的时候可能会有点没头绪，但完整跑通一次的流程之后，后面的操作基本就是重复这一过程。

---

## 主要文件

仓库中的核心文件主要包括：

```text
ZJU_AIAS_CODE/
│
├── main.py          # 模型推理 / 平台提交入口
├── train.py         # 模型训练脚本
├── 程序报告.docx     # 课程报告（仅供参考）
└── README.md
```

### `train.py`

用于在 MO 平台上训练模型。

通常需要根据具体作业修改：

- 数据集路径
- 模型配置
- 训练参数
- Epoch
- Batch Size
- Learning Rate
- 预训练权重路径
- 模型保存路径等

训练完成后，需要记录最终得到的 **模型权重文件路径**。

### `main.py`

用于加载训练好的模型并完成最终推理，也是平台评分时主要使用的代码。

需要重点检查：

- 模型权重路径
- API 配置
- 数据输入路径
- 模型加载方式
- 推理接口
- 输出格式

尤其需要注意：

> **`main.py` 中使用的模型权重必须和 `train.py` 最终训练得到的权重对应。**

---

### 提交并查看分数

确认程序能够正常运行之后，即可按照课程平台要求进行提交。

如果效果不理想，可以继续：

```text
修改模型 / 参数
      ↓
重新运行 train.py
      ↓
获得新的模型权重
      ↓
修改 main.py 中的权重路径
      ↓
重新测试
      ↓
再次提交
```

整个作业基本就是不断重复这一流程。
